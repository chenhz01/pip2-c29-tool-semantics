# Learning Cards

Four layers per card: **L0** a twelve-year-old can follow → **L1** the mechanism → **L2** how to use it → **limit** when it fails. Gap evidence follows each cluster.

## c29 工具语义（4 件）— 证据：`tool call` 生态集中在框架层，语义判定件缺位；v1 L55 是"工具自测"（功能对不对），本簇是"语义清不清"

- **L104 契约漂移检测**：L0 工具的说明书会悄悄变：参数改名、返回多字段。它定期对着真工具核对说明书，变了就喊。L1 缓存工具 schema 指纹，调用前比对，漂移 → 列差异并标记受影响调用点。L2 断言=①schema 变化被列出、②一致放行。
- **L105 超时语义**：L0 调用超时后有两种可能：它停了（可以重试）或它还在跑（重试会重复干活）。分不清就重试，是事故之源。L1 为每类调用标注超时语义（cancellable/uncancellable），不可取消类超时后禁止盲重试。L2 断言=①不可取消类拦截盲重试、②可取消类允许。
- **L106 结果新鲜度**：L0 工具返回的数据要贴"何时采的"标签：三秒前的股价能用，三天前的不能用。L1 为工具结果打时间戳，消费方校验年龄 vs 该数据类型的保鲜期，过期拒用。L2 断言=①过期数据拒用、②新鲜放行。
- **L107 重试退避策略**：L0 失败了别立刻疯狂重试——那样只会把对方打得更死。等一等、越等越久，才是礼貌的试法。L1 校验重试序列满足指数退避+上限（无连续零间隔、总次数封顶），违规拦截。L2 断言=①零间隔连击拦截、②合规退避放行。
